# 🏛️ Sistema de Gestão Institucional

Sistema web desenvolvido em **Python com Streamlit**, focado na geração
de **relatórios gerenciais e dashboards interativos**, utilizado em
ambiente institucional.

## 🛠️ Tecnologias Utilizadas
- Python
- Streamlit
- Pandas
- SQLite
- OpenPyXL

## 📊 Funcionalidades
- Relatório geral com filtros dinâmicos
- Relatório de desligados por período
- Exportação de dados em CSV e Excel
- Dashboards com indicadores visuais
- Interface organizada por abas (tabs)

## 📈 Destaque Técnico
O sistema utiliza:
- Manipulação avançada de datas
- Filtros dinâmicos por período e local
- Geração de relatórios automatizados
- Layout customizado com Streamlit (HTML + CSS inline)

## 🚀 Status do Projeto
✔️ Sistema em produção  
✔️ Utilizado em projeto institucional
